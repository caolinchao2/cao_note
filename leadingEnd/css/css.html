CSS 方法论简介 ​

  • BEM：.block__element--modifier，最流行
  • OOCSS：分离结构和皮肤
  • SMACSS：Base, Layout, Module, State, Theme 五类

  • Atomic CSS（如 Tailwind）：单一功能类

性能优化 ​

  1. 减少 CSS 文件大小，删除无用代码
  2. 避免使用 @import（改用 link）
  3. 合理使用选择器，避免嵌套过深
  4. 使用 CSS 预处理和后处理器
  5. 使用 content-visibility 延迟渲染
  6. 使用 will-change 提前告知浏览器优化属性
  7. 动画优先使用 transform 和 opacity（只触发合成层）

总结 ​

CSS 是网页设计的核心技术之一，用于控制网页的样式和布局。CSS3 引入了许多新特性，如圆角、阴影、渐变、变换、过渡、动画等，使得网页设计更加灵活和强大。

掌握 CSS 和 CSS3 需要理解其基本概念、选择器、盒模型、布局方式以及各种新特性，并通过实践不断积累经验。同时，需要关注浏览器兼容性和性能优化，编写高效、可维护的 CSS 代码。

随着 Web 技术的发展，CSS 也在不断演进，新的特性如 CSS Grid、CSS 变量、Flexbox、Container Queries、@layer、clamp() 等已经成为现代网页设计的标准。持续学习和掌握这些新特性，将有助于创建更加优秀的网页设计。
