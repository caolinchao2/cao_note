Elasticsearch ​

全文搜索引擎与分布式分析引擎，面向日志、搜索、可观测性的核心基础设施。

一、Elasticsearch 概述 ​

1.1 什么是 Elasticsearch ​

Elasticsearch 是一个基于 Apache Lucene 构建的分布式全文搜索引擎，提供近实时的搜索和分析能力。它通过 RESTful API 暴露所有操作，支持结构化查询、全文检索、聚合分析等多种能力。

1.2 核心特点 ​

特性说明
全文搜索基于 Lucene 倒排索引，支持分词、模糊匹配、相关性打分
近实时 (NRT)文档写入后约 1s 即可被搜索到（受 refresh_interval 控制）
分布式自动将数据分片到多台机器，支持水平扩展
RESTful API所有操作通过 HTTP/JSON 完成，语言无关
高可用副本分片确保节点宕机时数据不丢失
Schema-less动态映射允许直接写入无需预先定义结构
丰富的聚合支持 Metrics、Bucket、Pipeline 等多种聚合分析
生态完善Logstash、Kibana、Beats 等形成完整 ELK 技术栈

1.3 ELK 技术栈 ​

组件作用
Elasticsearch数据存储、搜索、分析引擎
Logstash数据采集、转换、传输（支持多种输入/输出插件）
Kibana数据可视化、仪表盘、管理界面

Elastic Stack（原 ELK Stack） 还包括：

  • Beats — 轻量级数据采集器（Filebeat 采集日志、Metricbeat 采集指标、Heartbeat 采集心跳）
  • APM Server — 应用性能监控
  • Elastic Agent — 统一的数据采集代理
  • Enterprise Search — 企业搜索（App Search、Workplace Search）

1.4 适用场景 ​

场景说明
全文搜索站内搜索、商品搜索、文档检索
日志分析集中式日志平台，实时分析和排查问题
APM应用性能监控，追踪请求链路与性能指标
安全分析SIEM，威胁检测，安全事件关联分析
指标分析业务指标、系统指标的实时聚合与可视化
地理查询基于地理位置的范围、距离查询

2.2 分布式概念 ​

概念说明
节点 (Node)一个 Elasticsearch 实例，是集群中的一个服务器
集群 (Cluster)一个或多个节点组成的集合，共同承载数据和负载
分片 (Shard)索引被拆分为多个分片，每个分片是一个 Lucene 实例
主分片 (Primary Shard)文档写入时首先写入的分片，索引创建时不可更改数量
副本分片 (Replica Shard)主分片的拷贝，提供高可用和读扩展
段 (Segment)Lucene 内部存储结构，分片由多个段组成

3.6 乐观锁（_seq_no 与 _primary_term） ​

Elasticsearch 使用 _seq_no（序列号）和 _primary_term（主分片任期）实现乐观并发控制。

bash

GET /my-index/_doc/1
# => _seq_no: 5, _primary_term: 1

# 仅在 _seq_no 匹配时更新（乐观锁）
PUT /my-index/_doc/1?if_seq_no=5&if_primary_term=1
{
  "title": "Elasticsearch 入门",

5.3 bool 查询 ​

bool 查询是 Elasticsearch 最常用的复合查询，支持四种关联子句：

子句说明评分影响
must必须匹配（AND），贡献评分是
filter必须匹配（AND），不贡献评分否（有缓存）

选主流程 ​

  1. 每个节点维护一个 known master 列表
  2. 当前 master 心跳超时后，有资格的节点发起选举
  3. 使用 Bully 算法（节点间按优先级比较，ID 最小的获胜）
  4. 获得超过半数（discovery.zen.minimum_master_nodes，或 ES 7.0+ 自动计算）的票数成为新 master
  5. 新 master 发布集群状态

ES 7.0+ 移除了 minimum_master_nodes，自动通过 discovery.seed_hosts 数量计算法定人数。

8.5 硬件建议 ​

资源建议
内存64GB 物理内存中分配 31GB 给 ES Heap（不超过 32GB 指针压缩限制）

B. 常用 Status Code ​

状态码含义
200 OK请求成功
201 Created创建成功
204 No Content删除成功
400 Bad Request请求格式错误
404 Not Found索引或文档不存在
409 Conflict版本冲突（乐观锁）
429 Too Many Requests请求被限流或队列满
503 Service Unavailable集群不可用（无 master）
