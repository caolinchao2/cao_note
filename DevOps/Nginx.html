1. Nginx 概述 ​

1.1 特点 ​

Nginx（engine-x）是一个高性能 HTTP 和反向代理服务器，由 Igor Sysoev 于 2004 年开发。

特性说明
高性能事件驱动架构（epoll/kqueue），单进程可处理数万并发
低内存同等并发下内存占用远低于 Apache
反向代理支持 HTTP/HTTPS/TCP/UDP 反向代理
负载均衡内置多种负载均衡算法
高扩展性模块化设计，支持丰富第三方模块
热部署平滑重载配置，平滑升级二进制

1.2 应用场景 ​

  • 静态文件服务 — 托管 HTML/CSS/JS/图片
  • 反向代理 — 转发请求到后端（Node.js/Java/Python）
  • 负载均衡 — 流量分发到多台后端
  • API 网关 — 统一入口，路由/限流/认证
  • SSL 终止 — 处理 HTTPS，后端用 HTTP 通信
  • 缓存加速 — 缓存静态内容或代理响应

2.2 main / events / http ​

nginx
user nginx;
worker_processes auto;                       # 工作进程数，通常等于 CPU 核心数
error_log /var/log/nginx/error.log warn;
pid /var/run/nginx.pid;
worker_rlimit_nofile 65535;                  # 进程最大文件描述符数

events {
    worker_connections 10240;                # 单 worker 最大并发连接
    multi_accept on;                         # 一次接受多个新连接

2.4 location 匹配规则 ​

3.1 root vs alias ​

root:   root 路径 + URI = 文件路径
alias:  alias 路径 + (URI - location路径) = 文件路径
root:   root 路径 + URI = 文件路径
alias:  alias 路径 + (URI - location路径) = 文件路径

2
nginx
location /static/ {
    root /var/www;
    # /static/css/style.css → /var/www/static/css/style.css
}

location /static/ {
    alias /data/files/;
    # /static/css/style.css → /data/files/css/style.css
}
location /static/ {
    root /var/www;
    # /static/css/style.css → /var/www/static/css/style.css

location /static/ {
    alias /data/files/;

13.2 403 Forbidden ​

  • 索引文件不存在 — 添加 index.html 或开启 autoindex
  • 文件权限不足 — chmod 755 /var/www && chown -R nginx:nginx /var/www
  • root/alias 路径错误 — 检查路径是否存在
  • deny all 限制 — 检查 allow/deny 规则
  • SELinux — getenforce 检查，setenforce 0 临时关闭

13.3 502 Bad Gateway ​

  • 后端未启动 — systemctl status node-server
  • 后端端口错误 — netstat -tlnp | grep 3000
  • 连接超时 — 增大 proxy_connect_timeout / proxy_read_timeout
  • 后端连接数打满 — 增加实例或优化连接池
  • PHP-FPM 问题 — 检查 socket 权限和 php-fpm 状态
