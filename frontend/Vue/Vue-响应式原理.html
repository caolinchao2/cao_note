Vue 响应式原理 ​

Vue2 响应式原理 ​

核心：Object.defineProperty ​

Vue2 通过 Object.defineProperty 将 data 的属性转为 getter/setter，实现数据劫持。

js
const obj = { name: '张三', age: 18 }

Object.keys(obj).forEach(key => {
  let value = obj[key]

  Object.defineProperty(obj, key, {
    enumerable: true,
    configurable: true,
    get() {
      console.log(`读取 ${key}: ${value}`)
      // 收集依赖
      return value
    },
    set(newValue) {
      console.log(`设置 ${key}: ${newValue}`)
      value = newValue
      // 触发更新
      dep.notify()
    }
  })
})

发布订阅模式 ​

Dep — 依赖收集器 ​

js
class Dep {
  constructor() {
    this.subs = [] // 存放订阅者（Watcher）
  }

  addSub(watcher) {
    this.subs.push(watcher)
  }

  notify() {
    this.subs.forEach(watcher => watcher.update())
  }
}

Watcher — 订阅者 ​

js
class Watcher {
  constructor(vm, key, callback) {
    this.vm = vm
    this.key = key
    this.cb = callback

    // 将当前 watcher 实例添加到 Dep.target
    Dep.target = this
    // 触发 getter，从而将 watcher 添加到 dep 的 subs 中
    key.split('.').reduce((obj, k) => obj[k], vm)
    Dep.target = null
  }

  update() {
    const value = this.key.split('.').reduce((obj, k) => obj[k], this.vm)
    this.cb(value)
  }
}

完整的数据劫持 ​

js
function observe(obj) {
  if (!obj || typeof obj !== 'object') return

  Object.keys(obj).forEach(key => {
    let value = obj[key]
    observe(value) // 递归处理深层对象

    const dep = new Dep()

    Object.defineProperty(obj, key, {
      enumerable: true,
      configurable: true,
      get() {
        // 收集依赖：如果 Dep.target 有值，添加订阅
        if (Dep.target) {
          dep.addSub(Dep.target)
        }
        return value
      },
      set(newValue) {
        if (newValue === value) return
        value = newValue
        observe(newValue) // 新值也要劫持
        dep.notify() // 发布通知
      }
    })
  })
}

数据代理 ​

Vue 将 data 的属性代理到 vm 实例上，方便通过 this.xxx 直接访问。

js
class Vue {
  constructor(options) {
    this.$data = options.data

    // 数据劫持
    observe(this.$data)

    // 数据代理：将 this.$data 的属性代理到 this 上
    Object.keys(this.$data).forEach(key => {
      Object.defineProperty(this, key, {
        enumerable: true,
        configurable: true,
        get() {
          return this.$data[key]
        },
        set(newValue) {
          this.$data[key] = newValue
        }
      })
    })
  }
}

数组的响应式处理 ​

Vue2 无法通过 Object.defineProperty 监听数组索引和 length 变化，因此通过重写数组方法实现：

js
const originalMethods = ['push', 'pop', 'shift', 'unshift', 'splice', 'sort', 'reverse']

originalMethods.forEach(method => {
  const original = Array.prototype[method]

  Object.defineProperty(arrayMethods, method, {
    value: function (...args) {
      const result = original.apply(this, args)
      // 触发更新
      this.__ob__.dep.notify()
      return result
    }
  })
})

js
// 1. 无法检测对象的属性添加或删除
this.obj.newKey = 'value'       // 非响应式
this.$set(this.obj, 'newKey', 'value')  // 响应式
Vue.set(this.obj, 'newKey', 'value')    // 同上

// 2. 无法通过索引直接修改数组
this.list[0] = newValue         // 非响应式
this.$set(this.list, 0, newValue)       // 响应式
this.list.splice(0, 1, newValue)        // 响应式

// 3. 无法直接修改数组 length
this.list.length = 0            // 非响应式

Vue3 响应式原理 ​

核心：Proxy ​

Vue3 使用 Proxy 替代 Object.defineProperty，解决了 Vue2 的所有限制。

js
const handler = {
  // 读取属性
  get(target, key, receiver) {
    console.log(`读取 ${key}`)
    track(target, key)      // 收集依赖
    return Reflect.get(target, key, receiver)
  },
  // 设置属性
  set(target, key, value, receiver) {
    console.log(`设置 ${key}: ${value}`)
    const result = Reflect.set(target, key, value, receiver)
    trigger(target, key)    // 触发更新
    return result
  },
  // 删除属性
  deleteProperty(target, key) {
    console.log(`删除 ${key}`)
    const result = Reflect.deleteProperty(target, key)
    trigger(target, key)
    return result
  }
}

const reactive = (obj) => new Proxy(obj, handler)

Proxy vs Object.defineProperty ​

特性Object.definePropertyProxy
监听方式遍历对象属性逐个劫持代理整个对象
新增/删除属性无法监听，需用 $set/$delete自动监听
数组监听需重写数组方法自动监听索引和 length
嵌套对象需要递归处理访问时懒递归
性能初始化时全量递归按需拦截，性能更好
兼容性IE9+不支持 IE

Vue3 响应式 API ​

js
import { reactive, ref, computed, watch, watchEffect } from 'vue'

// reactive — 对象响应式（基于 Proxy）
const state = reactive({ count: 0, user: { name: '张三' } })
state.count++          // 视图更新
state.newKey = 'new'   // 视图更新（Vue2 做不到）

// ref — 基本类型响应式
const count = ref(0)
count.value++          // ref 需要通过 .value 访问

// computed
const double = computed(() => count.value * 2)

// watch
watch(count, (newVal, oldVal) => {
  console.log(`count 从 ${oldVal} 变为 ${newVal}`)
})

// watchEffect — 自动追踪依赖
watchEffect(() => {
  console.log(`count 变化了：${count.value}`)
})

响应式原理对比总结 ​

Vue2:
  data → observe() → Object.defineProperty → getter/setter
    → 每个属性一个 Dep → 收集 Watcher → 数据变化时 notify()

Vue3:
  data → reactive() → Proxy → 拦截 get/set/deleteProperty
    → 每个属性一个 dep（Map）→ 收集 effect → 数据变化时 trigger()
Vue2:
  data → observe() → Object.defineProperty → getter/setter
    → 每个属性一个 Dep → 收集 Watcher → 数据变化时 notify()

Vue3:
  data → reactive() → Proxy → 拦截 get/set/deleteProperty
    → 每个属性一个 dep（Map）→ 收集 effect → 数据变化时 trigger()
