1. Lambda 表达式 ​

1.1 什么是 Lambda 表达式？ ​

Lambda 表达式是 Java 8 引入的一种新的语法，允许将函数作为方法参数，或者将代码作为数据处理。

1.2 Lambda 表达式的语法 ​

(参数列表) -> { 代码块 }
(参数列表) -> { 代码块 }
1

简化规则：

  • 如果参数列表只有一个参数，可以省略括号
  • 如果代码块只有一条语句，可以省略大括号和分号
  • 如果代码块只有一条 return 语句，可以省略 return 关键字

1.3 Lambda 表达式的使用 ​

1.3.1 替代匿名内部类 ​

java
// 传统匿名内部类
Runnable runnable1 = new Runnable() {
    @Override
    public void run() {
        System.out.println("Traditional Runnable");
    }
};

// Lambda 表达式
Runnable runnable2 = () -> System.out.println("Lambda Runnable");

// 启动线程
new Thread(runnable1).start();
new Thread(runnable2).start();
new Thread(() -> System.out.println("Inline Lambda")).start();

1.3.2 函数式接口 ​

Lambda 表达式只能用于函数式接口（只有一个抽象方法的接口）。

内置函数式接口：

  • Predicate<T>：接收一个参数，返回布尔值
  • Consumer<T>：接收一个参数，无返回值
  • Function<T, R>：接收一个参数，返回一个结果
  • Supplier<T>：无参数，返回一个结果
  • BiFunction<T, U, R>：接收两个参数，返回一个结果

示例：

java
// Predicate：用于过滤
Predicate<String> isLongerThan5 = str -> str.length() > 5;
boolean result = isLongerThan5.test("Java"); // false

// Consumer：用于消费数据
Consumer<String> printUpperCase = str -> System.out.println(str.toUpperCase());
printUpperCase.accept("Java"); // "JAVA"

// Function：用于转换数据
Function<String, Integer> stringToLength = str -> str.length();
int length = stringToLength.apply("Java"); // 4

// Supplier：用于提供数据
Supplier<Double> randomDouble = () -> Math.random();
double random = randomDouble.get();

// BiFunction：用于处理两个数据
BiFunction<Integer, Integer, Integer> add = (a, b) -> a + b;
int sum = add.apply(5, 3); // 8
// Predicate：用于过滤
Predicate<String> isLongerThan5 = str -> str.length() > 5;

// Supplier：用于提供数据
Supplier<Double> randomDouble = () -> Math.random();
double random = randomDouble.get();

// BiFunction：用于处理两个数据
BiFunction<Integer, Integer, Integer> add = (a, b) -> a + b;
int sum = add.apply(5, 3); // 8

2. Stream API ​

2.1 什么是 Stream？ ​

Stream 是 Java 8 引入的一种新的抽象，用于处理集合数据。Stream 不是数据结构，而是一个计算流程。

2.2 Stream 的特点 ​

  • 无存储：Stream 不存储数据，只是通过数据源的操作管道进行计算
  • 函数式编程：Stream 操作是函数式的，不会修改原始数据源
  • 惰性求值：中间操作是惰性的，只有当终端操作执行时才会执行
  • 可消费：Stream 只能被消费一次，一旦被消费，就不能再使用

2.3 Stream 的操作流程 ​

  1. 创建 Stream：从数据源创建 Stream
  2. 中间操作：对 Stream 进行转换、过滤、排序等操作
  3. 终端操作：触发计算，生成结果

3. Optional 类 ​

3.1 什么是 Optional？ ​

Optional 是 Java 8 引入的一个容器类，用于表示可能为 null 的值。Optional 类的目的是避免 NullPointerException。

3.2 Optional 的使用 ​

3.2.1 创建 Optional 对象 ​

// 创建非空 Optional

Optional<String> nonEmptyOptional2 = Optional.ofNullable("Java"); // 如果传入 null，返回空 Optional
Optional<String> nullOptional = Optional.ofNullable(null); // 空 Optional

4. 日期时间 API ​

4.1 为什么需要新的日期时间 API？ ​

Java 8 之前的日期时间 API 存在以下问题：

  • Date 类设计不佳，月份从 0 开始
  • Calendar 类也存在类似问题，且不是线程安全的
  • 没有统一的日期时间处理标准

4.2 新的日期时间 API 核心类 ​

  • LocalDate：表示日期（年、月、日）
  • LocalTime：表示时间（时、分、秒、纳秒）
  • LocalDateTime：表示日期和时间
  • ZonedDateTime：表示带时区的日期和时间
  • Instant：表示时间戳
  • Duration：表示两个时间之间的间隔
  • Period：表示两个日期之间的间隔
  • DateTimeFormatter：用于日期时间的格式化和解析

4.3 LocalDate、LocalTime、LocalDateTime ​

java
// LocalDate：日期
LocalDate today = LocalDate.now(); // 当前日期
LocalDate specificDate = LocalDate.of(2023, 12, 25); // 指定日期（2023-12-25）
LocalDate parsedDate = LocalDate.parse("2023-12-25"); // 解析日期字符串

// 获取日期组件
int year = today.getYear(); // 年份
Month month = today.getMonth(); // 月份（枚举类型）
int dayOfMonth = today.getDayOfMonth(); // 日
DayOfWeek dayOfWeek = today.getDayOfWeek(); // 星期几（枚举类型）
int dayOfYear = today.getDayOfYear(); // 一年中的第几天

// 修改日期
LocalDate tomorrow = today.plusDays(1); // 明天
LocalDate lastMonth = today.minusMonths(1); // 上个月
LocalDate firstDayOfMonth = today.withDayOfMonth(1); // 本月第一天

// LocalTime：时间

5. 模块化系统 ​

5.1 什么是模块化？ ​

模块化是 Java 9 引入的一种新的特性，允许将代码组织成模块，每个模块包含一组相关的包和资源。

5.2 模块化的好处 ​

  • 更好的封装：可以控制模块之间的依赖关系
  • 减少内存占用：只加载需要的模块
  • 提高安全性：可以限制模块之间的访问
  • 更好的可维护性：模块之间的依赖关系清晰

5.3 模块的定义 ​

模块声明文件：module-info.java

java
// 模块声明
module com.example.myapp {
    // 导出包：允许其他模块访问该包
    exports com.example.myapp.api;
    exports com.example.myapp.service;
    
    // 依赖其他模块
    requires java.base; // 隐式依赖，不需要显式声明
    requires java.sql; // 依赖 java.sql 模块
    requires transitive java.xml; // 传递依赖，依赖该模块的模块也会依赖 java.xml
    
    // 提供服务：实现某个服务接口
    provides com.example.myapp.Service with com.example.myapp.impl.ServiceImpl;
    
    // 使用服务：声明使用某个服务
    uses com.example.myapp.Service;
    
    // 打开包：允许其他模块通过反射访问该包
    opens com.example.myapp.internal to java.base;
}

6. 虚拟线程 ​

6.1 什么是虚拟线程？ ​

虚拟线程是 Java 19 引入的一种轻量级线程，是 JVM 级别的线程，不是操作系统级别的线程。虚拟线程的创建和切换成本很低，可以创建数百万个虚拟线程。

6.2 虚拟线程的特点 ​

  • 轻量级：创建和切换成本低
  • 大量创建：可以创建数百万个虚拟线程
  • 简化异步编程：允许使用同步编程模型编写异步代码
  • 兼容现有 API：可以使用现有的 Thread API

6.3 虚拟线程的使用 ​

java
// 创建虚拟线程
Runnable task = () -> {
    System.out.println("Virtual thread: " + Thread.currentThread().getName());
    try {
        Thread.sleep(Duration.ofSeconds(1));
    } catch (InterruptedException e) {
        e.printStackTrace();
    }
};

// 方式 1：使用 Thread.ofVirtual()
Thread virtualThread1 = Thread.ofVirtual()
    .name("my-virtual-thread")
    .start(task);

// 方式 2：使用 Executors.newVirtualThreadPerTaskExecutor()
try (ExecutorService executor = Executors.newVirtualThreadPerTaskExecutor()) {
    for (int i = 0; i < 1000; i++) {
        final int taskId = i;
        executor.submit(() -> {
            System.out.println("Task " + taskId + " running on " + Thread.currentThread().getName());
            Thread.sleep(Duration.ofMillis(500));
            return taskId;
        });
    }
}

// 方式 3：使用 Thread.Builder
Thread.Builder.OfVirtual builder = Thread.ofVirtual();
Thread virtualThread2 = builder.name("another-virtual-thread").unstarted(task);
virtualThread2.start();

// 等待虚拟线程完成
try {
    virtualThread1.join();
    virtualThread2.join();
} catch (InterruptedException e) {
    e.printStackTrace();
}

// 密封类
public sealed class Shape permits Circle, Rectangle, Triangle {
    // 抽象方法
    public abstract double getArea();
}

// 允许继承的子类
public final class Circle extends Shape {
    private final double radius;
    
    public Circle(double radius) {
        this.radius = radius;
    }
    
    @Override
    public double getArea() {
        return Math.PI * radius * radius;
    }
}

public non-sealed class Rectangle extends Shape {
    private final double width;
    private final double height;
    
    public Rectangle(double width, double height) {
        this.width = width;
        this.height = height;
    }
    
    @Override
    public double getArea() {
        return width * height;
    }
}

public final class Triangle extends Shape {
    private final double base;
    private final double height;
    
    public Triangle(double base, double height) {
        this.base = base;
        this.height = height;
    }
    
    @Override
    public double getArea() {
        return 0.5 * base * height;
