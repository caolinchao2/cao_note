Java 基础笔记 ​

1. Java 简介 ​

1.1 什么是 Java？ ​

Java 是一种面向对象的编程语言，由 Sun Microsystems（现在是 Oracle）开发。它的设计目标是：

  • Write Once, Run Anywhere (WORA) - 一次编写，到处运行
  • 简单、面向对象、分布式、健壮、安全、平台无关、可移植、高性能
  • 多线程、动态

1.2 Java 平台 ​

  • Java SE (Standard Edition) - 标准版，用于开发桌面应用
  • Java EE (Enterprise Edition) - 企业版，用于开发企业级应用（现已迁移到 Jakarta EE）
  • Java ME (Micro Edition) - 微型版，用于嵌入式设备（已被 Android 取代）

1.3 Java 版本历史 ​

  • Java 8 (2014) - Lambda 表达式、Stream API、Optional 等
  • Java 11 (2018) - 长期支持版本 (LTS)
  • Java 17 (2021) - 最新长期支持版本 (LTS)
  • Java 21 (2023) - 最新特性版本

2. Java 开发环境搭建 ​

2.1 JDK、JRE、JVM 区别 ​

  • JVM (Java Virtual Machine) - Java 虚拟机，负责执行 Java 字节码
  • JRE (Java Runtime Environment) - Java 运行时环境，包含 JVM 和核心类库
  • JDK (Java Development Kit) - Java 开发工具包，包含 JRE 和开发工具

2.2 安装 JDK ​

  1. 下载 JDK：访问 Oracle 官网 或 OpenJDK
  2. 安装 JDK，注意安装路径
  3. 配置环境变量：
    • JAVA_HOME - JDK 安装路径
    • PATH - 添加 %JAVA_HOME%\bin
  4. 验证安装：
    bash
    java -version
javac -version

2.3 开发工具 ​

  • IDE：IntelliJ IDEA（推荐）、Eclipse、NetBeans
  • 文本编辑器：VS Code + Java 插件、Sublime Text

8.2 封装 ​

封装是将数据和操作数据的方法绑定在一起，对外部隐藏实现细节。

访问修饰符：

  • public：公开，任何类都可以访问
  • protected：受保护，同一包或子类可以访问
  • default（默认）：同一包可以访问
  • private：私有，只有本类可以访问

8.3 继承 ​

继承允许一个类（子类）继承另一个类（父类）的属性和方法。

语法：

java
// 父类
public class Animal {
    public void eat() {
        System.out.println("Eating...");
    }
}

// 子类继承父类
public class Dog extends Animal {
    public void bark() {
        System.out.println("Barking...");
    }
}

// 使用
Dog dog = new Dog();
dog.eat(); // 继承自父类
dog.bark(); // 子类自己的方法
// 父类
public class Animal {
    public void eat() {
        System.out.println("Eating...");

11. 异常处理 ​

11.1 什么是异常？ ​

异常是程序运行时发生的错误，Java 使用异常机制来处理错误情况。

11.2 异常分类 ​

  • Checked Exception（受检异常）：必须处理，如 IOException, SQLException
  • Unchecked Exception（非受检异常）：可选处理，如 NullPointerException, ArrayIndexOutOfBoundsException
  • Error：严重错误，如 OutOfMemoryError, StackOverflowError

11.3 异常处理关键字 ​

  • try：包含可能抛出异常的代码
  • catch：捕获并处理异常
  • finally：无论是否发生异常，都会执行
  • throw：抛出异常
  • throws：声明方法可能抛出的异常

11.4 异常处理示例 ​

java
try {
    // 可能抛出异常的代码
    int[] arr = {1, 2, 3};
    int num = arr[5]; // ArrayIndexOutOfBoundsException
} catch (ArrayIndexOutOfBoundsException e) {
    // 处理异常
    System.out.println("数组索引越界：" + e.getMessage());
} catch (Exception e) {
    // 捕获其他异常
    System.out.println("发生异常：" + e.getMessage());
} finally {
    // 清理资源
    System.out.println("finally 块执行");
}

// 抛出异常
public void checkAge(int age) throws IllegalArgumentException {
    if (age < 0) {
        throw new IllegalArgumentException("年龄不能为负数");
    }
}

13. 包装类与枚举（面试高频坑） ​

13.1 包装类与自动装箱拆箱 ​

Java 为 8 种基本类型提供了对应的包装类：Integer、Long、Double、Float、Boolean、Byte、Short、Character。

自动装箱（Autoboxing）： 基本类型 → 包装类 自动拆箱（Unboxing）： 包装类 → 基本类型

java
Integer a = 100;       // 自动装箱：Integer.valueOf(100)
int b = a;             // 自动拆箱：a.intValue()
Integer a = 100;       // 自动装箱：Integer.valueOf(100)
int b = a;             // 自动拆箱：a.intValue()

Integer 缓存池（高频坑） ​

Integer.valueOf() 对 -128 ~ 127 范围内的值做了缓存，这个范围内返回的是同一个对象：

java
Integer a = 100;        // Integer.valueOf(100) → 缓存池命中
Integer b = 100;        // 同一个缓存对象
System.out.println(a == b);       // true  （同一个对象）

Integer c = 200;        // Integer.valueOf(200) → 超出缓存范围，new Integer
Integer d = 200;        // 另一个 new Integer
System.out.println(c == d);       // false （不同对象）

System.out.println(c.equals(d));  // true  （值相等）
