Python 深度学习（PyTorch） ​

基于 PyTorch 的深度学习入门，涵盖核心概念、模型构建与训练流程。

深度学习概述 ​

深度学习是机器学习的一个子领域，其核心是使用多层神经网络从数据中自动学习特征表示。与传统机器学习方法不同，深度学习无需手工设计特征，而是通过端到端的学习方式自动提取层次化的特征。

深度学习的典型应用 ​

  • 计算机视觉：图像分类、目标检测、语义分割、人脸识别
  • 自然语言处理：文本分类、机器翻译、情感分析、问答系统
  • 语音识别：语音转文字、说话人识别
  • 推荐系统：用户行为预测、个性化推荐
  • 强化学习：游戏 AI、机器人控制、自动驾驶

为什么选择 PyTorch ​

PyTorch 由 Meta（原 Facebook）于 2016 年开源，凭借其简洁的设计与出色的灵活性，迅速成为学术研究与工业部署的主流深度学习框架。

PyTorch vs TensorFlow ​

当前（2025）市场格局 ​

PyTorch 在学术界已是绝对主流，绝大多数顶会论文（CVPR、ICCV、NeurIPS、ICLR 等）基于 PyTorch 实现。在工业界，PyTorch 通过 TorchScript、TorchServe 和 ONNX 导出等工具链，已广泛部署于生产环境。TensorFlow 仍在使用 Keras 的团队和部分已有基础设施的大厂中存在，但新项目选型普遍倾向 PyTorch。

对比维度PyTorchTensorFlow
计算图动态图（Define-by-Run）2.x 默认 Eager Execution，但历史包袱重
调试体验原生 Python 调试器（pdb）直接可用需要 tfdbg，调试体验相对笨重
学习曲线平缓，接近 NumPy 风格较陡峭，API 分层复杂
生态torchvision、torchaudio、torchtext、HuggingFaceTF Hub、TF Datasets、Keras
生产部署TorchServe、ONNX、LibTorch（C++）TF Serving、TF Lite、TF.js
分布式训练原生 DDP（Distributed Data Parallel）tf.distribute.Strategy
社区活跃度极高，学术界首选依赖 Google 维护，社区热度下降

核心差异解读 ​

动态图 vs 静态图：PyTorch 的执行方式是与 Python 运行时同步的，每一行代码执行时图结构即时构建，这使得条件分支和循环可以直接使用 Python 原生语法。TensorFlow 1.x 时代需要先构建静态计算图再通过 Session 执行，调试极为不便。TensorFlow 2.x 虽默认启用了 Eager Execution，但其底层架构仍保留了静态图的复杂性。

调试体验：在 PyTorch 中，你可以在前向传播的任何位置插入 print() 或 breakpoint()，就像调试普通 Python 代码一样。TensorFlow 的调试则需要通过 tf.print()（张量打印需在图中执行）或 tf.debugging 工具集，体验上不如 PyTorch 直观。

何时选择 PyTorch ​

  • 学术研究、论文复现、快速原型开发
  • 需要灵活的动态图控制流（如循环神经网络、树形结构模型）
  • 团队以 Python 工程师为主，希望降低学习成本
  • 需要与 HuggingFace Transformers、Diffusers 等现代生态集成

何时仍可考虑 TensorFlow ​

  • 已有大规模 TensorFlow 生产基础设施，迁移成本过高
  • 需要移动端部署（TFLite）或 Web 端部署（TF.js）
  • 团队深度绑定 Google Cloud 生态（TPU、Vertex AI）

PyTorch 核心概念 ​

Autograd（自动微分） ​

Autograd 是 PyTorch 的自动微分引擎，它是训练神经网络的基础。通过记录张量上的所有操作，Autograd 能够自动计算梯度。

python
# ── 基本原理 ──────────────────────────────────────────

# 创建需要梯度的张量
x = torch.randn(3, requires_grad=True)
print(x.requires_grad)  # True

y = x * 2               # 记录计算图
z = y.mean()            # 继续向前传播

z.backward()            # 反向传播，计算梯度
print(x.grad)           # 查看 x 的梯度值

# 手动验证梯度：
# z = mean(y) = 1/3 * (y0 + y1 + y2)
# y = 2 * x
# dz/dx_i = dz/dy_i * dy_i/dx_i = (1/3) * 2 = 2/3
print(x.grad)           # tensor([0.6667, 0.6667, 0.6667])

# ── 梯度累积与清零 ────────────────────────────────────

# 默认情况下，梯度会累积
for _ in range(3):
    y = (x * 2).mean()
    y.backward()
print(x.grad)  # 梯度值累积了 3 次

# 需要手动清零
x.grad.zero_()

# ── 停止追踪梯度 ──────────────────────────────────────

# 推理阶段或冻结参数时，可用 torch.no_grad() 禁用梯度追踪
with torch.no_grad():
    y = x * 2         # 此处不会记录计算图
    print(y.requires_grad)  # False

# 等价方法：detach()
y = x.detach()        # 返回新的张量，不追踪梯度

# ── requires_grad 设置 ────────────────────────────────

# 修改已有张量的 requires_grad
x.requires_grad_(True)   # 原地修改
x.requires_grad_(False)  # 关闭梯度追踪

# 查看梯度是否有效
print(x.requires_grad)   # bool

Autograd 工作原理简述：前向传播时，PyTorch 会动态构建一个计算图（DAG，有向无环图），图中的每个节点是一个张量，每条边代表操作。调用 backward() 时，Autograd 沿着计算图从输出到输入遍历，利用链式法则计算每个参数的梯度。计算完成后，该计算图被自动释放以供下一轮使用（默认为动态图，每次迭代重新构建）。

构建神经网络 ​

nn.Module ​

nn.Module 是所有神经网络模块的基类。自定义模型时，你需要继承它并实现 __init__（定义层）和 forward（定义前向传播逻辑）。

python
import torch.nn as nn
import torch.nn.functional as F

class SimpleNet(nn.Module):
    """一个简单的全连接网络：784 → 256 → 10"""
    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear(784, 256)    # 第一层：784 维输入 → 256 维隐藏层
        self.relu = nn.ReLU()             # ReLU 激活函数
        self.fc2 = nn.Linear(256, 10)     # 第二层：256 维 → 10 维输出（分类数）

    def forward(self, x):
        """
        前向传播
        x shape: [batch_size, 784]
        """
        x = self.fc1(x)
        x = self.relu(x)
        x = self.fc2(x)
        return x  # 原始 logits，未经过 softmax

# 实例化模型
model = SimpleNet()
print(model)

# 查看模型参数
for name, param in model.named_parameters():
    print(f"{name}: {param.shape}")

# 前向传播
dummy_input = torch.randn(32, 784)   # batch_size=32
output = model(dummy_input)
print(output.shape)  # torch.Size([32, 10])

但使用继承 nn.Module 的方式更为灵活，便于添加复杂控制流（条件分支、循环、多输入等）。

常用网络层 ​

python
# ── 全连接层（Linear） ────────────────────────────────
nn.Linear(in_features=784, out_features=256, bias=True)

# ── 卷积层（Conv2d） ──────────────────────────────────
nn.Conv2d(
    in_channels=3,      # 输入通道数（RGB 图像为 3）
    out_channels=16,    # 输出通道数（卷积核数量）
    kernel_size=3,      # 卷积核大小 3×3
    stride=1,           # 步长
    padding=1,          # 填充（保持空间尺寸）
    padding_mode="zeros"
)

# ── 池化层 ────────────────────────────────────────────
nn.MaxPool2d(kernel_size=2, stride=2)  # 最大值池化，尺寸减半
nn.AvgPool2d(kernel_size=2, stride=2)  # 平均池化
nn.AdaptiveAvgPool2d((1, 1))           # 自适应池化到指定尺寸

# ── Dropout ───────────────────────────────────────────
nn.Dropout(p=0.5)       # 训练时随机丢弃 50% 的神经元（防止过拟合）
nn.Dropout2d(p=0.2)     # 针对卷积层的通道级 Dropout

# ── 批归一化 ──────────────────────────────────────────
nn.BatchNorm1d(num_features=256)    # 全连接层后使用
nn.BatchNorm2d(num_features=16)     # 卷积层后使用（通道维）

# ── 激活函数 ──────────────────────────────────────────
nn.ReLU()
nn.LeakyReLU(negative_slope=0.01)
nn.Sigmoid()       # 二分类输出层
nn.Tanh()
nn.Softmax(dim=1)  # 多分类概率输出
nn.LogSoftmax(dim=1)  # 常与 nn.NLLLoss 配合使用

def train_model(model, train_loader, val_loader, criterion, optimizer,
                num_epochs, device, save_path="best_model.pth"):
    """完整训练流程，包含验证和模型保存"""
    best_acc = 0.0

    for epoch in range(num_epochs):
        # ── 训练阶段 ──
        model.train()
        train_loss = 0.0
        for inputs, labels in train_loader:
            inputs, labels = inputs.to(device), labels.to(device)

            optimizer.zero_grad()
            outputs = model(inputs)
            loss = criterion(outputs, labels)
            loss.backward()
            optimizer.step()

            train_loss += loss.item()

        # ── 验证阶段 ──
        model.eval()
        val_loss = 0.0
        correct = 0
        total = 0
        with torch.no_grad():
            for inputs, labels in val_loader:
                inputs, labels = inputs.to(device), labels.to(device)
                outputs = model(inputs)
                loss = criterion(outputs, labels)

                val_loss += loss.item()
                _, predicted = torch.max(outputs, 1)
                total += labels.size(0)
                correct += (predicted == labels).sum().item()

        val_acc = 100.0 * correct / total

        print(f"Epoch [{epoch+1}/{num_epochs}] "
              f"Train Loss: {train_loss/len(train_loader):.4f} "
              f"Val Loss: {val_loss/len(val_loader):.4f} "
              f"Val Acc: {val_acc:.2f}%")

        # 保存最佳模型
        if val_acc > best_acc:
            best_acc = val_acc
            torch.save(model.state_dict(), save_path)
            print(f"  -> Model saved (best acc: {best_acc:.2f}%)")

    print(f"Training completed. Best accuracy: {best_acc:.2f}%")
    return best_acc

迁移学习 ​

迁移学习是利用在大规模数据集（如 ImageNet）上预训练的模型，针对特定任务进行微调的技术。它能在数据量有限时显著提升模型性能。

python
import torchvision.models as models

# ── 加载预训练模型 ────────────────────────────────────

# ResNet-18（ImageNet 预训练）
resnet = models.resnet18(pretrained=True)

# 其他可用模型
# models.resnet50(pretrained=True)
# models.vgg16(pretrained=True)
# models.densenet121(pretrained=True)
# models.efficientnet_b0(pretrained=True)
# models.mobilenet_v2(pretrained=True)

# ── 方法一：特征提取器（冻结所有层，仅训练分类头） ─────

# 冻结所有参数
for param in resnet.parameters():
    param.requires_grad = False

# 查看原始分类头
print(resnet.fc)  # Linear(in_features=512, out_features=1000, bias=True)

# 替换分类头（假设新任务有 5 个类别）
num_classes = 5
resnet.fc = nn.Linear(resnet.fc.in_features, num_classes)

# 只有分类头的参数需要梯度（约 0.4% 的参数）
trainable_params = sum(p.numel() for p in resnet.parameters() if p.requires_grad)
total_params = sum(p.numel() for p in resnet.parameters())
print(f"Trainable: {trainable_params:,} / Total: {total_params:,} "
      f"({100 * trainable_params / total_params:.2f}%)")

# ── 方法二：全模型微调（解冻部分层） ──────────────────

# 先冻结全部
for param in resnet.parameters():
    param.requires_grad = False

# 解冻最后几个残差块
for param in resnet.layer4.parameters():
    param.requires_grad = True

# 分类头始终可训练
resnet.fc = nn.Linear(512, num_classes)

# ── 训练迁移学习模型 ──────────────────────────────────

model = resnet.to(device)
criterion = nn.CrossEntropyLoss()

# 不同层使用不同学习率（分类头学习率更大）
optimizer = optim.Adam([
    {"params": model.layer4.parameters(), "lr": 0.0001},

])

迁移学习适用场景 ​

场景建议策略数据量要求
新数据集与 ImageNet 高度相似冻结全部特征提取层，只训练分类头数百张即可
新数据集差异较大（如医学影像）解冻后几层 + 新分类头进行微调数千张起
数据量充足全模型微调，但使用较低学习率上万张
新任务与预训练任务完全不同可以仅使用预训练权重初始化，全局微调需要较多数据

保存与加载的注意事项 ​

  1. torch.save(model.state_dict(), ...) 是推荐方式，仅保存参数，不耦合模型结构定义
  2. 加载时需先实例化相同结构的模型，再调用 load_state_dict
  3. map_location=device 参数用于在不同设备间迁移（GPU → CPU 或 CPU → GPU）
  4. 推理前务必调用 model.eval() 关闭 Dropout 和 BatchNorm 的训练行为
  5. 如需在保存后继续训练，务必保存优化器状态和学习率调度器状态

学习路线 ​

  1. 掌握基础：确保理解 Python、NumPy 和 PyTorch Tensor 的基本操作
  2. 从经典数据集开始：MNIST → Fashion-MNIST → CIFAR-10，逐步增加难度

  4. 动手实现标准模型：自己实现简单的全连接网络和 CNN，而不是直接调用高层 API
  5. 使用 TensorBoard：养成监控训练过程的习惯，观察损失曲线和准确率变化
  6. 逐步增加复杂度：全连接网络 → 简单 CNN → 残差网络 → 预训练模型微调
  7. 阅读和复现论文：从经典论文（AlexNet、VGG、ResNet）开始，尝试复现核心结果

避坑指南 ​

  • 不要在验证/测试时忘记调用 model.eval()——Dropout 会灾难性地影响结果
  • 不要在训练时忘记调用 optimizer.zero_grad()——梯度会不断累积
  • 数据增强时，注意只在训练集上使用，验证/测试集仅做标准化
  • 迁移学习时，预训练模型的标准化参数（mean/std）必须与原训练数据一致
  • 保存模型推荐使用 state_dict 而非整个模型，确保兼容性
  • 分布式训练时，注意 batch_size 的含义是 每个 GPU 的 batch_size
