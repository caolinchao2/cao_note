Go 基础 ​

Go 语言语法与工程基础，面向 Java / Python 后端工程师的零基础到可上手指南。

一、Go 语言定位与设计哲学 ​

1.1 Go 是什么 ​

Go（又称 Golang）是 Google 于 2009 年发布的开源静态类型编译语言，设计目标是解决 C++ / Java 在后端大规模系统中的编译慢、并发难写、依赖失控三大痛点。它有三个关键词：

  • 简单：语言规范极简，关键字仅 25 个，没有继承、没有泛型历史包袱（1.18 才引入泛型）、没有异常机制。
  • 高效：编译为原生机器码，启动毫秒级，单二进制分发，内存占用远低于 JVM 系语言。
  • 并发内建：goroutine 与 channel 是语言级特性，而非像 Java 那样依赖 Thread 类与锁库。

1.2 与 Java / Python 的整体对照 ​

维度GoJavaPython
类型系统静态强类型静态强类型动态弱类型（渐进式）
运行方式编译为原生二进制JVM 字节码解释执行
并发模型goroutine + channelThread + 锁 / Loom协程 + GIL
对象模型结构体 + 方法（无继承）class 继承体系class / 多继承
错误处理显式 error 返回try/catch 异常try/except 异常
依赖管理go modMaven / Gradlepip / poetry / uv

典型场景云原生、网关、微服务企业级后端脚本、AI、Web

1.3 适用场景与反模式 ​

适合：高并发网络服务（网关、代理、IM）、云原生基础设施（Kubernetes、Docker 即 Go 写）、CLI 工具、中间件。

不适合：强业务 ORM 模板化开发（生态弱于 Java）、科学计算与 AI（生态弱于 Python）、复杂 GUI。

三、模块与包管理 go mod ​

3.1 从 GOPATH 到 Go Modules ​

Go 1.11 前所有代码必须放在 GOPATH/src 下且无版本概念（vendor 手动管理），被戏称为"包管理石器时代"。Go 1.11 引入 Modules，Go 1.16 默认开启。模块（module）是一个带 go.mod 的根目录，go.mod 同时承担了 Java pom.xml 与 package.json 的职责。

3.4 包（package）与可见性 ​

  • 一个目录下所有 .go 文件属于同一个包，包名一般等于目录名。
  • 包内标识符首字母大写 = 导出（public），小写 = 包内私有，没有 Java 的 protected/private 多级关键字。
  • 约定俗成：main 包编译为可执行程序，其余为库包。
go
// 文件 service/user.go，包名 service
package service

// User 首字母大写，外部可见（导出类型建议写注释，golint 会检查）
type User struct {
    Name string // 导出字段
    age  int    // 私有字段，仅包内可访问
}

func NewUser(name string) *User { return &User{Name: name} } // 工厂函数模式

func (u *User) private() {} // 包内方法

7.3 append 扩容原理 ​

go
s := make([]int, 0, 3)
s = append(s, 1, 2, 3)
s := make([]int, 0, 3)
s = append(s, 1, 2, 3)
1
2
  • 当 len == cap 时 append 会分配新数组：容量小于 256 时翻倍，之后按约 1.25 倍增长（Go 1.18 起的增长公式），并把旧元素拷过去。
  • append 可能返回新底层数组，所以必须用返回值接收：s = append(s, x)。
  • 跨包共享时可用 copy(dst, src) 显式复制，或 slices.Clone（Go 1.21+）避免误改。

8.1 string 的本质 ​

string 是只读的字节切片，底层不存字符而是 UTF-8 字节。len(s) 返回字节数而非字符数：

s := "你好go"

10.4 循环变量捕获（Go 1.22 前） ​

Go 1.22 前 for 循环变量是复用的同一个变量，闭包延迟执行会全部取到最后值：

go
// Go 1.22 前的输出：5 5 5 5 5
for i := 0; i < 5; i++ {
    go func() { fmt.Println(i) }()
}
// Go 1.22 前的输出：5 5 5 5 5
for i := 0; i < 5; i++ {
    go func() { fmt.Println(i) }()
}

旧版本需用参数拷贝：go func(n int) { fmt.Println(n) }(i)。Go 1.22 起每次迭代是新变量，行为符合直觉，升级后无需 workaround。

10.5 格式化与命名习惯 ​

  • 官方强制 gofmt，无需争论风格；命名推荐驼峰（导出首字母大写）。
  • 错误处理走"快乐路径"：先判断 error 提前 return，主逻辑下沉，减少嵌套。
  • 善用 _ 忽略不需要的返回值，但 error 永远不要用 _ 丢弃，除非明确该错误可忽略。
